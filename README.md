# My Recipes — iPhone PWA

A phone-first personal recipe tracker with a milk-white and pastel-purple interface.

## Features
- Save recipes locally on one phone using IndexedDB.
- Upload a cover image and extra food/process photos.
- Categories start empty so you create only the tags you want.
- Reusable custom category tags.
- Preset pastel category colors plus a full custom color picker.
- Search, filter by category, and favorites.
- Edit Order mode for dragging recipe cards into a custom portfolio order.
- Touch drag-and-drop ordering for ingredients, steps, and extra photos.
- Install on iPhone Home Screen as a standalone web app.

## Update on GitHub Pages
Upload the new `index.html`, `manifest.json`, `service-worker.js`, and `icons` folder to the same GitHub repository and commit the changes. Keep the same filenames. The installed Home Screen app will continue using the same GitHub Pages URL.

## v5 appearance update
